# Política de seguridad

Guardia protege personas y bienes: una vulnerabilidad es grave. Si encuentras una, **no la publiques**; escribe al responsable del proyecto (agrega aquí un correo de contacto antes de publicar el repositorio) con los pasos para reproducirla. Se confirmará la recepción y se corregirá antes de divulgarla.

Alcance: servidor (`servidor/`), analizador (`analizador/`) y panel (`web/`). Fuera de alcance: cámaras y routers de terceros.

Buenas prácticas de despliegue: HTTPS obligatorio, tokens por dispositivo, 2FA para todas las personas, cambiar las claves de fábrica de las cámaras, no exponer RTSP a internet y mantener las dependencias al día (Dependabot está configurado).
